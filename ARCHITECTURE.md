# AICLEX Document Portal - Technical Architecture Documentation

## 1. Executive Summary
The AICLEX Document Portal is a high-performance, multi-tenant web application designed for automated candidate document verification. It leverages modern cloud technologies and Artificial Intelligence to streamline the KYC (Know Your Customer) and onboarding process for large-scale organizations.

## 3. System Architecture

### 3.1 Frontend Architecture
The application uses a **Component-Based Architecture** following Next.js best practices:
- **Client Components:** Interactive forms, data tables, and real-time UI updates.
- **Server Components:** Efficient data fetching and initial page rendering to reduce client-side overhead.
- **State Management:** React Hooks (useState, useMemo) and Zod for robust client-side validation.

### 3.2 Backend & API Layer
- **Unified API Infrastructure:** Custom API routes handle complex logic like document processing and bulk exports.
- **Server Actions:** Secure, direct server-side functions for form submissions and administrative actions.
- **Middleware:** A specialized edge middleware manages authentication and routing based on user roles (Admin, Vendor, Candidate).

### 3.3 Data Architecture (Multi-Tenancy)
The system uses a **Shared Database, Isolated Rows** approach for multi-tenancy:
- **Master Data:** Large-scale employee records indexed by `clientId` and `employeeId`.
- **Relational Integrity:** Prisma ORM ensures strict type safety and data integrity across 10+ core models (Candidates, Documents, Clients, etc.).

### 3.4 AI & OCR Pipeline
1. **Upload:** User uploads a document (Image/PDF) to Cloudflare R2.
2. **Processing:** The system triggers Google Document AI to extract key metadata (Name, ID Numbers, Dates).
3. **Validation:** Extracted data is cross-referenced with Master Data in real-time to prevent fraud and errors.
4. **Correction:** A sophisticated OCR mapping layer handles diverse document formats (Aadhaar, PAN, Marksheets).

---

## 4. Infrastructure & Security
- **Data Security:** All sensitive documents are stored in private Cloudflare R2 buckets with signed URL access.
- **Auth Flow:** Role-based access control (RBAC) ensures Vendors only see their candidates, while SuperAdmins manage the entire ecosystem.
- **Scalability:** Next.js architecture allows for horizontal scaling, while the PostgreSQL database handles thousands of concurrent transactions.

---

## 5. Deployment Workflow
- **Version Control:** Managed via GitHub with automated branch protection.
- **Production Server:** High-availability VPS running Ubuntu.
- **Process Manager:** PM2 ensures zero-downtime reloads and automatic recovery.
